## Project Overview
UniApp X project (uvue + uts) targeting Android. Electric scooter rental app with booking, payment, and user management.

## uvue CSS Constraints (MUST follow)

uvue only supports a **strict subset** of CSS. Violations cause compilation errors.

### Selectors
- **Only class selectors** (`.foo`) are allowed
- NO tag selectors (`view`, `text`, `page`, etc.)
- NO attribute selectors (`.btn[disabled]`) — use class binding instead: `:class="['btn', disabled ? 'btn-disabled' : '']"`
- NO pseudo-classes (`:hover`, `:first-child`, `:nth-child`)
- NO combinators (`.parent > .child`, `.a + .b`)

### Properties & Values
| Property | Allowed Values | NOT Allowed |
|---|---|---|
| `display` | `flex`, `none` | `block`, `inline`, `grid`, `inline-block` |
| `min-height` | number (px) | `%`, `vh`, `auto` |
| `font-weight` | `normal`, `bold`, `400`-`700` | `800`, `900`, `100`-`300` |
| `gap` | Warning only — may not work, use margins as fallback |
| `backdrop-filter` | Warning only — may not render |
| `position` | `relative`, `absolute`, `fixed` | `sticky` |

### Common Fixes
- `display: block` → `display: flex` (text elements are flex by default in uvue)
- `min-height: 100%` → `min-height: 1000px` (or use scroll-view)
- `.btn[disabled]` → add class via `:class="['btn', isDisabled ? 'btn-disabled' : '']"`
- `font-weight: 800` → `font-weight: 700`
- Global tag selectors in App.uvue → remove entirely (box-sizing is default in uvue)
